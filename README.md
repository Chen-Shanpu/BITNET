# BITNET Repository Guide

This repository contains the CPU and GPU inference kernels, model setup scripts, and kernel-tuning utilities used for BitNet-style low-bit inference.

## Repository Layout

| Path | Purpose |
| --- | --- |
| `src/` | CPU inference kernel sources and detailed CPU optimization notes |
| `include/` | Public headers and generated kernel configuration targets |
| `gpu/` | CUDA kernels, GPU conversion scripts, and GPU usage guide |
| `utils/` | Conversion, benchmarking, tuning, and visualization helpers |
| `model_configs/` | Small model config fixtures used by tuning and tests |
| `preset_kernels/` | Checked-in preset kernel configurations used by `setup_env.py` |
| `tuned_kernels/` | Example tuned kernel outputs generated by `tune_all_models.py` |
| `tuning_logs/` | Example tuning logs and generated visualizations |
| `docs/` | Additional documentation such as code generation notes |
| `tests/` | Python tests for the tuning utilities |
| `assets/`, `media/`, `src/assets/` | Images and media referenced by docs |

## Main Entry Points

- `python setup_env.py` — prepare the environment, download/convert models, and select preset kernels.
- `python run_inference.py` — run local inference.
- `python run_inference_server.py` — start the inference server.
- `python tune_all_models.py` — benchmark model shapes and generate tuned kernel configs/reports.

## Documentation Map

- CPU optimization details: `src/README.md`
- GPU usage: `gpu/README.md`
- Code generation notes: `docs/codegen.md`

## Generated Files

The repository now ignores common local artifacts such as:

- Python caches (`__pycache__/`, `*.pyc`)
- build outputs (`build/`, `cmake-build-*`, `compile_commands.json`)
- local runtime/model directories (`logs/`, `models/`, `checkpoints/`)
- generated include files written by setup scripts (`include/bitnet-lut-kernels.h`, `include/kernel_config.ini`)

This keeps local experimentation from polluting the tracked source tree.
